# Chat Application UI

## Overview
The Chat Application UI is a modern, responsive front-end interface for a real-time messaging application. It provides users with an intuitive and user-friendly experience for chatting with individuals or groups. This project focuses on designing an attractive and interactive user interface using modern web technologies.

## Features
- Responsive design for desktop, tablet, and mobile devices
- User authentication screens (Login & Sign Up)
- Interactive chat interface
- Contact/Chat list sidebar
- Real-time message display (UI)
- Message input with send button
- Profile section
- Search contacts
- Dark and Light mode support
- Clean and modern user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- Bootstrap 5
- Font Awesome
- Google Fonts

## UI Components
- Login Page
- Registration Page
- Home Dashboard
- Chat Window
- Contact List
- User Profile
- Settings Panel

## Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/chat-application-ui.git
```

2. Navigate to the project folder:
```bash
cd chat-application-ui
```

3. Open `index.html` in your web browser.
